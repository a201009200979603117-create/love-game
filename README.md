# love-game

戀愛視覺小說《心動的每一天》，以及節奏小遊戲《心動節拍》。

- `index.html`：視覺小說本篇
- `rhythm.html`：節奏小遊戲（主選單的「♪ 節奏小遊戲：心動節拍」也能進入）

## 心動節拍（節奏遊戲）

四軌下落式音遊。音符落到判定線時按下對應的按鍵，手機和平板直接點擊軌道。

| 操作 | 按鍵 |
| --- | --- |
| 四條軌道 | `D` `F` `J` `K` |
| 暫停／繼續 | `Esc` |

- **判定**：PERFECT（±45ms）、GREAT（±90ms）、GOOD（±150ms）、MISS
- **長押音符**：按住直到尾端；中途放開算 MISS
- **評級**：S ≥ 95%、A ≥ 90%、B ≥ 80%、C ≥ 70%，其餘為 D
- **柳如煙**會依照連擊、失誤和最後的評級給出不同的表情與台詞
- 結算畫面會顯示平均偏差，並建議「判定偏移」要調多少

### 歌曲

| 歌曲 | 說明 |
| --- | --- |
| 心跳的節拍 | 原創曲，128 BPM。整首歌用 Web Audio 即時合成，譜面直接由樂譜產生，和音樂完全對齊 |
| 心動的每一天 | 故事的主題曲 `audio/bgm.mp3`，譜面由程式分析音樂後自動生成 |
| 自選音樂 | 載入任何音樂檔，同樣自動生成譜面 |

每首歌都有簡單、普通、困難三種難度。

> 主題曲需要用網頁伺服器開啟（例如 GitHub Pages 或 `python3 -m http.server`）才讀得到；
> 直接雙擊 html 檔開啟時，瀏覽器會擋住讀取，這時可以用「自選音樂」載入 `audio/bgm.mp3`。

### 程式結構

| 檔案 | 內容 |
| --- | --- |
| `rhythm/game.js` | 遊戲主程式：判定、繪圖、輸入、選曲、設定、結算 |
| `rhythm/chart.js` | 自動譜面：用頻譜通量找出音樂的起音，再依難度分配軌道、雙押與長押（不依賴 DOM，Node.js 也能執行） |
| `rhythm/song-heartbeat.js` | 原創曲的樂譜、合成器音色與手工譜面規則 |
| `rhythm/rhythm.css` | 樣式 |

想新增一首合成曲，可以參考 `song-heartbeat.js`：`MELODY` 是旋律（`音名:拍數`），`STRUCTURE` 是曲式與和弦，`buildChart()` 決定每個難度要放哪些音符。
